🍕 Pizza Sales Analysis Using SQL
A SQL-based data analysis project exploring pizza sales performance, order patterns, product popularity, and revenue trends.
📌 Project Overview
This project uses SQL queries to analyze pizza sales data and answer business questions at three levels: Basic, Intermediate, and Advanced. The queries progress from overall sales metrics to time-based trends, revenue contribution, and category-level product rankings.
🎯 Objectives
- Measure total orders and revenue.
- Identify popular pizza sizes and top-selling pizza types.
- Analyze sales across pizza categories and hours of the day.
- Calculate daily order patterns and average pizzas ordered per day.
- Evaluate pizza-type revenue contribution and cumulative revenue trends.
- Rank the top-performing pizza types within each category.
🧰 Tools and Skills
- Tool: SQL
- Concepts: SELECT, aggregate functions, JOIN, GROUP BY, ORDER BY, filtering, date/time analysis, revenue calculations, cumulative analysis, and ranking.
📊 Analysis and Business Questions
1. Basic Analysis
1. Retrieve the total number of orders placed.
2. Calculate the total revenue generated from pizza sales.
3. Identify the highest-priced pizza.
4. Identify the most common pizza size ordered.
5. List the top 5 most ordered pizza types along with their quantities.
2. Intermediate Analysis
1. Join the necessary tables to find the total quantity of each pizza category ordered.
2. Determine the distribution of orders by hour of the day.
3. Join relevant tables to find the category-wise distribution of pizzas.
4. Group the orders by date and calculate the average number of pizzas ordered per day.
5. Determine the top 3 most ordered pizza types based on revenue.
3. Advanced Analysis
1. Calculate the percentage contribution of each pizza type to total revenue.
2. Analyze the cumulative revenue generated over time.
3. Determine the top 3 most ordered pizza types based on revenue for each pizza category.
💡 SQL Techniques Demonstrated
- Aggregations: COUNT(), SUM(), and AVG()
- Joins: Combining related sales tables for deeper analysis
- Grouping and sorting: GROUP BY and ORDER BY
- Top-N analysis: Finding the most popular pizza types and highest revenue contributors
- Time-based analysis: Examining order distribution by hour and sales by date
- Revenue analysis: Calculating percentage contribution and cumulative revenue
- Category-level ranking: Comparing top pizza types within each category
▶️ How to Use
1. Open the SQL script(s) in this repository.
2. Load the project dataset into a compatible SQL database.
3. Run the queries to reproduce the analysis, adapting table or column names if your database schema differs.
